## BurnIn Test Tool SOP for TINKERBOARD_3_RV##
1. ./BurnIn_TINKERBOARD_3_RV.sh
2. Enter test case number, and start test


## System Test Tool SOP for TINKERBOARD_3_RV##

1. Shutdown test
        ./System_test_TINKERBOARD_3_RV_shutdown.sh
2. Reboot test
        ./System_test_TINKERBOARD_3_RV_reboot.sh
3. Suspend/Resume test
        ./System_test_TINKERBOARD_3_RV_suspend.sh

If want to stop Shutdown and Reboot test
        ./System_test_TINKERBOARD_3_RV_stop.sh

If want to select by menu
        ./System_test_TINKERBOARD_3_RV.sh
